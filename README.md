# Subrat Sethi | Personal Portfolio

A modern, responsive personal portfolio website built with **React** and **Bootstrap** to showcase my skills, projects, experience, and education.

🌐 **Live Demo:** [https://myportfolio-0b8f.onrender.com](https://myportfolio-0b8f.onrender.com)  
💻 **Source Code:** [https://github.com/Subrat-IO/MyPortfolio](https://github.com/Subrat-IO/MyPortfolio)

---

## Features

- **Responsive Design:** Works seamlessly on desktop, tablet, and mobile.  
- **About Section:** Brief introduction and background.  
- **Education & Experience:** Highlights academic achievements and professional experience.  
- **Work/Projects:** Showcase of completed projects with descriptions.  
- **Contact Form:** Allows visitors to get in touch directly.  
- **Image Gallery:** Display of relevant images and portfolio visuals.  

---

## Tech Stack

- **Frontend:** React.js  
- **Styling:** Bootstrap 5  
- **Deployment:** Render

## Installation & Setup

To run the project locally:

```bash
# Clone the repository
git clone https://github.com/Subrat-IO/MyPortfolio.git

# Navigate to the project directory
cd MyPortfolio

# Install dependencies
npm install

# Start the development server
npm start
